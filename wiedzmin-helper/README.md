# Wiedźmin: Stary Świat — Pomocnik

Przeglądarkowy przewodnik do planszówki **Wiedźmin: Stary Świat** (sama **podstawka**).

Prowadzi przez:

1. **Wybór liczby graczy** + **imiona i szkoły** wiedźmińskie
2. **Przygotowanie rozgrywki** — krok po kroku (plansza, talie, potwory, każdy gracz)
3. **Turę gracza** — faza I → II → III, z gałęziami (ruch, walka, medytacja, eksploracja)
4. **Wariant solo** — osobny setup i różnice w pokerze, walce, fazie III oraz tabeli wyniku
5. **Ściągę** + **Leksykon** (atrybuty, zdolności szkół, kroki walki) + **Źródła** (instrukcja, FAQ, skróty YT/forów)
6. **Nie zastępuje kart** — pełne teksty potworów/eliksirów/eksploracji zostają na stole (prawa CDPR)

## Uruchomienie

Wystarczy otworzyć `index.html` w przeglądarce **albo** odpalić lokalny serwer w tym folderze:

```bash
cd wiedzmin-helper
python3 -m http.server 8080
```

Potem wejdź na: http://127.0.0.1:8080

> Moduły ES wymagają serwera HTTP (albo GitHub Pages) — samo otwarcie pliku `file://` może nie zadziałać w części przeglądarek.

## GitHub Pages

W ustawieniach repozytorium włącz Pages (branch `main` / ten branch, folder `/wiedzmin-helper` albo root z tą zawartością). Adres będzie w stylu:

`https://<user>.github.io/<repo>/wiedzmin-helper/`

## Zakres

- Tylko podstawka (bez dodatków)
- Solo + 2–5 graczy
- Język: polski
- Fanowski skrót instrukcji — przy sporze wygrywa oficjalna książka zasad
